# Лабораторная работа №1 — «На кухне»

**Ермаков Максим, K3440. Вариант 5:** сервис для обмена рецептами и кулинарных блогов.

Сайт выполнен на HTML, CSS, Bootstrap 5.3.8 и обычном JavaScript. Сборщик, npm и серверная часть не нужны.

## Запуск

Откройте `index.html` в браузере. Все стили, скрипты, шрифт и фотографии находятся в папке лабораторной. Для видео нужен доступ к YouTube.

Для удобного просмотра через локальный сервер можно выполнить из этой папки:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная, подборки по категориям, поиск и ссылки на блоги |
| `recipes.html` | Поиск по названию и фильтры по типу блюда, сложности и ингредиентам |
| `recipe.html?id=pasta` | Рецепт с фото, ингредиентами, пошаговыми инструкциями, видео, лайками и комментариями |
| `blogs.html` | Кулинарные статьи и подписки на авторов |
| `profile.html` | Сохранённые рецепты, публикации, подписки и добавление рецепта |
| `login.html` | Форма входа |
| `register.html` | Форма регистрации с проверкой совпадения паролей |

## Реализованные требования ЛР1

- Вёрстка средствами HTML, CSS и Bootstrap; адаптивные колонки, навигация, карточки, формы, вкладки, модальные окна и уведомления.
- Вход, регистрация и личный кабинет пользователя.
- Поиск рецептов и совместная фильтрация по типу, сложности и ингредиентам. Несколько ингредиентов вводятся через запятую; рецепт должен содержать каждый из них.
- Страница каждого рецепта с фотографией, списком ингредиентов, пошаговыми инструкциями и встроенным видео. Есть отдельная ссылка на видео, если плеер недоступен.
- Лайки, комментарии и подписки на кулинаров.
- Сохранённые рецепты и собственные публикации в личном кабинете.
- JavaScript обрабатывает формы, фильтры и социальные действия. Bootstrap открывает модальные окна, переключает вкладки и мобильное меню.

## Как проверить

1. Зарегистрируйте пользователя; сначала попробуйте разные пароли, затем одинаковые (от 6 символов).
2. В каталоге выберите «Основные блюда», «Легко» и ингредиенты `томаты, чеснок`. Останется паста. Сбросьте фильтры.
3. Откройте пасту, сохраните рецепт, поставьте лайк, подпишитесь на автора и оставьте комментарий. Обновите страницу: действия сохранятся.
4. Откройте «Моя кухня»: рецепт находится в сохранённых, автор — в подписках.
5. Нажмите «Поделиться рецептом», заполните форму и опубликуйте блюдо. Оно появится в «Моих публикациях» и в общем каталоге. Можно использовать видеоссылку `https://www.youtube.com/watch?v=lWaBh-r2ZP0` для рецепта пасты.
6. Проверьте сайт на ширине 320–390 пикселей: меню раскрывается кнопкой, колонки перестраиваются, формы остаются доступными.

## Как устроен код

- `css/style.css` — общая палитра, логотип, оформление блоков и медиазапросы.
- `js/data.js` — массивы рецептов, авторов и статей.
- `js/common.js` — работа с хранилищем браузера, карточки, сохранение, лайки и подписки.
- `js/recipes.js` — каталог и категории на главной.
- `js/recipe.js` — детали рецепта и комментарии.
- `js/auth.js` — демонстрационные формы входа и регистрации.
- `js/profile.js` — личный кабинет и публикация рецепта.
- `js/blogs.js` — статьи в модальном окне и список кулинаров.
- `vendor/` — готовые файлы Bootstrap и Bootstrap Icons.
- `assets/` — локальные изображения и шрифт логотипа.

Для ЛР1 авторизация демонстрационная: принимаются корректный email и пароль от 6 символов. Пароли не сохраняются и не проверяются на сервере. Имя и email зарегистрированного пользователя запоминаются. Опция «Запомнить меня» выбирает между `localStorage` и `sessionStorage`.

Сохранения, лайки и подписки привязаны к email пользователя. Комментарии и публикации сохраняются в `localStorage` этого браузера. Реальную авторизацию и API можно добавить в следующих лабораторных. Для публикации фото выбирается из готовой подборки.
