# ЛР3 — На кухне

Ермаков Максим, K3440. Вариант 5: сервис домашних рецептов и кулинарных блогов.

Приложение из ЛР1 и ЛР2 перенесено на Vue 3. Vue Router открывает страницы без полной перезагрузки, а Axios обращается к API на JSON Server. Оформление, фотографии и тестовые данные перенесены из ЛР2.

## Запуск

Нужен Node.js 22.12+ из ветки 22 или Node.js 24 и новее. В папке `lab3` выполните:

```sh
npm ci
npm start
```

Откройте [http://localhost:3001](http://localhost:3001). Команда собирает интерфейс в `dist` и запускает сервер, который отдаёт приложение и API по адресу `/api`. При первом запуске сервер создаёт `server/db.json` из `server/seed.json`. Изменения сохраняются в этой базе.

Для разработки запустите `npm run api` и `npm run dev` в двух терминалах. Откройте адрес, который выведет Vite (обычно [http://localhost:5173](http://localhost:5173)). Vite передаст запросы `/api` серверу на порту 3001. Если он занят, укажите одинаковый `PORT` для обеих команд, например `PORT=3002 npm run api` и `PORT=3002 npm run dev`.

Тестовый вход — `anna@example.com` и `kitchen123`. Также можно создать новый аккаунт.

## Устройство приложения

- `src/router.js` задаёт маршруты главной страницы, каталога, рецепта, блогов, входа, регистрации и кабинета. В `src/main.js` проверяется наличие сессии при переходе в кабинет.
- `src/views` содержит страницы. В `src/components` находятся карточки рецептов, блогов и авторов, форма публикации и общие элементы интерфейса.
- `src/api/client.js` настраивает Axios и добавляет токен сессии к запросам.
- `src/composables/useRequest.js` используется для загрузки данных страниц, отменяет устаревшие запросы и предоставляет состояния загрузки и ошибки. `useRecipes.js` используется на главной и в каталоге. `useKitchen.js` отвечает за общий список авторов, лайки, сохранения и подписки. `useSession.js` и `useFeedback.js` управляют сессией и сообщениями интерфейса.
- `server/index.cjs` предоставляет API ЛР2 и возвращает `index.html` при прямом открытии маршрута Vue. Рабочая база исключена из Git.
- `GET /api/catalog` принимает поисковую строку `query`, ингредиенты через запятую, тип, сложность и номер страницы. Сервер сначала применяет фильтры, затем возвращает одну страницу карточек и общее число совпадений. Каталог показывает до 12 карточек за раз, а состав и шаги загружаются при открытии рецепта.

## Сценарий для проверки

Найдите рецепт по названию и ингредиентам. Откройте карточку, войдите, сохраните рецепт, поставьте лайк, подпишитесь на автора и оставьте комментарий. В кабинете проверьте сохранения и подписки, затем опубликуйте свой рецепт. Откройте каталог и обновите страницу рецепта по прямой ссылке. Для проверки статической сборки выполните `npm run build`.
